# Tic-Tac-Toe

A responsive two-player Tic-Tac-Toe game built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or start a local static server from this folder:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## How to play

- Players take turns placing X and O.
- Get three marks in a row, column, or diagonal to win.
- **New round** keeps the score and starts over.
- **Reset score** clears both scores and starts a fresh round.
